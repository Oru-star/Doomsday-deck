## Planned Features

| Feature | What it adds |
|---|---|
| **Offline LoRa communication** | A Waveshare SX1262 LoRa module is planned for low-data-rate messaging without relying on cellular service or internet access. Range depends on antenna, terrain, configuration, and local radio rules. |
| **Modular GPIO expansion** | A custom carrier board exposes a 40-pin SBC header and expansion interfaces for add-on hardware.|
| **Secondary e-paper display** | A 2.13-inch tri-colour e-paper HAT is planned for low-power status or reference information!!! |
| **Scroll/encoder input** | An M5Stack Scroll Unit is planned for navigation or shortcut control Along with a joystick for better navigation . |
| **Software-defined radio** | An RTL-SDR Blog V3 receiver is included as a self-sourced USB accessory for receive-only RF experimentation
| **Active cooling** | Two 5 V 4010 fans to move air through the enclosure. |
| **Custom enclosure** | A modular 3D-printed enclosure houses the display, keyboard, compute board, battery system, and some freee space for expansion hardware.|
